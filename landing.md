This is a pivot to a "Digital Tactile" aesthetic. Based on the reference image (Acctual), you want high-fidelity realism mixed with clean typography. It should feel less like a "hacker tool" and more like a "magic utility."

Here is the design spec for a pure, light-mode, Apple-esque landing page.



I. Design Language: "Tangible Utility"

The Vibe: Airy, crisp, and substantial. It shouldn't feel "flat" like a standard SaaS; it should feel like you can reach into the screen.

Color Palette:

Canvas: Pure White (#FFFFFF) or very subtle Porcelain (#F5F5F7).

Typography: Jet Black (#111111) for headings; Cool Grey (#64748B) for body.

Accent (The "Magic"): A single, vibrant "Blurple" or Royal Blue (#3B82F6) used sparingly (only on the recording cursor or active states).

Shadows: Soft, diffused, realistic shadows (Apple style) to lift elements off the page. No hard outlines.

Typography:

Headings: Inter Tight or SF Pro Display (Heavy weight, tight letter spacing, -2% tracking).

Body: Inter (Regular weight, relaxed line height).

Visual Style:

No "Code Blocks": Do not show terminal windows. Show "Actions" as tangible cards.

Floating Elements: Similar to the reference image’s floating paperclips/money, we will use 3D-rendered Cursors and "Action Bubbles" floating in white space.

II. Layout & Copy Specification

1. The Navigation (Non-existent)

Action: No header bar. No hamburger menu.

Top Center: A small, modest logo (e.g., a simple geometric shape) and the company name in bold sans-serif. That’s it.

2. The Hero Section (The Promise)

Layout: Large centered text. Below the text, a beautiful, high-fidelity UI mockup of the "Recorder" interface.



Headline (H1): Massive, black, heavy font.



Turn a browser session into an API.

Subtitle (H2): Medium grey, max-width 600px.



Don't write scrapers. Just show us what to do. Browse the web, record your actions, and we’ll turn that workflow into a production-ready API you can sell or scale.

CTA:

Style: Black pill-shaped button (#000000), white text, medium bold. Hover: lifts slightly.

Copy: Start Recording — Free

The Hero Visual (The "Magic"):

Instead of code, show a "Glass" Browser Window in the center.

Inside the window, a video plays of a cursor selecting a flight price.

The "Tactile" Detail: As the cursor clicks, a 3D "bubble" pops out of the button that says Extract: $450. It feels like a physical interaction.

Surrounding Elements: Floating around the central window (like the money/paperclips in your reference) are 3D glossy icons representing specific apps: A flight ticket, a LinkedIn logo, a CSV file icon, and a JSON file icon. They float gently in 3D space.

3. The Feature Section (The Reliability)

Layout: A single row of three clean, white cards. No borders, just soft drop shadows to separate them from the white background.



Vibe: These cards should look like "specs" or "instruction manuals"—very clean.

Feature 1: The Input



Visual: A realistic 3D Mouse Cursor icon.

Title: Teach by doing

Copy: Enter a goal like "Find leads on LinkedIn." We spin up a virtual browser, and you simply click through the workflow once to demonstrate it.

Feature 2: The Resilience (The Stack)



Visual: A stack of 3 rounded layers (representing the fallback system).

Title: Self-healing automation

Copy: The API adapts. We use exact selectors, AI vision, and agentic re-learning to ensure your API works even if the website changes its layout.

Feature 3: The Output



Visual: A glossy, metallic "Key" icon (representing the API key).

Title: Monetize your workflow

Copy: We package your recording into a secure API endpoint. Use it to power your own apps, or gate it behind a paywall and sell the data.

4. The Minimal Footer

Layout: Lots of white space above it to let the page breathe.



Content:

Small copyright text in light grey (#A1A1AA).

Two links: Documentation | Twitter.

No columns, no sitemap.

III. Animation & Interaction (The "Apple" Feel)

Parallax Floating: The floating 3D icons (ticket, CSV, JSON) in the hero section should move slightly as the user moves their mouse, creating depth.

Smooth Reveal: The text shouldn't "fade in." It should slide up gently (translateY) with a custom bezier curve that feels heavy and premium.

Video Polish: The recording demo inside the hero image needs to be high frame rate (60fps) and smoothed out. It shouldn't look like a jittery screen recording; it should look like a motion graphic.
